# 🏠 ALX Listing App: Property Detail

The property detail milestone of the ALX Airbnb-style listing app, built with **Next.js**, **TypeScript** and **Tailwind CSS**.

## Features

- Dynamic route **`/property/[id]`** for each listing
- `PropertyDetail`: image gallery, description, amenities, host information
- `BookingSection`: price per night, date inputs and a total
- `ReviewSection`: guest reviews with ratings
- Reusable `Button`, `Card` and `Pill` components

## Run it

```bash
git clone https://github.com/Dwaynemaster007/alx-listing-app-detail.git
cd alx-listing-app-detail
npm install
npm run dev   # http://localhost:3000
```
